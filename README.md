

✔️ Versão refinada

Abstract: é a base comum entre classes relacionadas, compartilhando atributos e comportamentos.

Interface: define uma característica ou capacidade que pode ser implementada por diferentes classes, mesmo sem relação direta entre elas.

🧠 Ajuste sutil (importante)

👉 Na abstract não é só “o que têm em comum”
→ é também reutilização de código + estrutura base

👉 Na interface não é só “característica”
→ é um contrato obrigatório de comportamento

🔥 Versão curta pra falar rápido:

Abstract define o que algo é. Interface define o que algo pode fazer.

Polimorfismo

Polimorfismo é a capacidade de objetos diferentes responderem de formas distintas ao mesmo método, permitindo flexibilidade e reutilização de código.
